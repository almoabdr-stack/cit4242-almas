# AAB project

## Overview
This project is an Advanced Programming (CIT4242) semester-long web application built with Java 21 and Spring Boot. The goal of the system is to provide a backend API service for managing [e.g., books, user orders, inventory, and user authentications].

## Key Features
* **Item Catalog Management:** Create, read, update, and delete [e.g., books / products / tasks].
* **User Services:** Allow users to register, log in, and manage their profiles.
* **Order / Transaction Processing:** Handle user requests, track statuses, and interact with a persistent database.
* **RESTful API:** Expose clean JSON endpoints for frontend or third-party integrations.

## Tech Stack
* **Language:** Java 21
* **Framework:** Spring Boot 3
* **Build Tool:** Maven (using Maven Wrapper)
* **Database:** PostgreSQL (configured for upcoming weeks)
